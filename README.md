# ONE SIZE — Premium Demo v4

This is a frontend demo only. Products are demo data so search, categories, wishlist, product details, cart and checkout can be tested now. Later the demo product array in `script.js` will be replaced by a secure API that reads products and creates orders in Odoo.

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages.

## Odoo architecture
Do not put Odoo credentials in browser JavaScript. Recommended flow:
Browser → secure backend/API → Odoo.

The social/contact details are intentionally placeholders until the official links are supplied.
